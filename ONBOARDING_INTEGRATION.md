## Как это работает

- Онбординг запускает **менеджер** (роль `admin`/`pm`/`owner` — как и доступ к панели менеджера в `control.py`) через «🎓 Онбординг новичков» → «➕ Начать онбординг»: выбирает новичка из активных сотрудников без текущего онбординга, затем ментора.
- **Новичок** видит «📊 Мой прогресс» на главном экране: чек-лист по фазам (день 1 / дни 2-5 / недели 2-3 / день 21 / дни 28-30), 5 ключевых правил, кнопку теста (со дня 21) и кнопку фото бара.
- **Ментор** (тот, чей `telegram_id` стоит в `mentor_id`) может отмечать пункты чек-листа вместе с новичком и оставлять текстовый фидбэк.
- **Инциденты новичка** фиксируются отдельно от общего «🆘 Инцидент» (тот — для всех сотрудников): менеджер/ментор выбирает новичка → категорию (8 категорий с готовой серьёзностью Лёгкая/Средняя/Критичная) → описание. Пишется в `incidents_reports` и, если настроен `GOOGLE_SHEETS_SPREADSHEET_ID`, дублируется строкой в лист `OnboardingIncidents`.
- **Тест дня 21** — 8 вопросов, порог 80%, результат сохраняется в `OnboardingProgress.quiz_results`.
- **Решение (день 21-30)** — менеджер в карточке новичка жмёт Принять / Продлить / Отказать → `complete_onboarding()`, новичок получает уведомление.

## Не реализовано (сознательно, вне зоны бота)

- **Ставка во время испытания** — в исходных файлах цифры расходятся (50%/70%/75%/85%/100% в разных разделах документа). Автоматический расчёт зарплаты в бот не встроен — это вопрос к финансовой модели (`ramo-finance`), не к тех. интеграции. Нужно решение, какой вариант верный, прежде чем автоматизировать.
- **Рассылка фото бара в общий чат** — в `.env` нет ID рабочего чата («Стоп-лист» и т.п.), поэтому фото пока только сохраняются в БД и видны менеджеру через карточку новичка (`get_onboarding_shift_photos`). Добавить чат — добавить `WORK_GROUP_ID` в `.env` и один `bot.send_photo(...)` в `photo_received()`.
- **`log/03_Reshenia.md`** — файл ведётся вручную в проекте `CLAUDE_AGENTS_RAMO`, бот его не трогает; при решении по новичку менеджеру нужно продублировать запись туда самому (или это можно на следующем шаге автоматизировать через файловую запись/API, если файл должен обновляться и с сервера).

## Как проверить локально

```bash
cd AMO-dev
venv\Scripts\activate
python -m bot.main
```
В Telegram: `/start` → зарегистрироваться (или взять существующего тестового пользователя) → как admin/pm/owner открыть «⚙️ Настройки» → «🔧 Режим модерации» недоступен для онбординга (он в общем меню) — сама панель менеджера открывается через «👥 Контроль команды» на home screen (доступно `admin`/`pm`/`owner`).
